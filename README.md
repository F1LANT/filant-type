# Filant Type

Голосовой ввод по клавише для Windows. Зажмите клавишу (по умолчанию CapsLock), скажите фразу,
отпустите: текст появится там, где стоит курсор, а если поля ввода нет, окажется в буфере обмена.

Распознавание работает на вашем компьютере (модель GigaAM v3 от Сбера): голос и текст никуда не
отправляются. Интернет нужен один раз, чтобы скачать модель (892 МБ).

## Обновления

Программа сама проверяет этот репозиторий: при запуске и раз в 6 часов. Новая версия скачивается
в фоне и ставится, когда вы не диктуете. Каждое обновление подписано ключом автора, файл с чужой
подписью программа не установит.

## Если Windows предупреждает

Установщик не подписан платным сертификатом, поэтому Windows может показать «Windows защитила ваш
компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».
